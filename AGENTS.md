### Project Overview

PulseCoach is a mobile-first personal trainer PWA built with Next.js 15 (App Router), TypeScript, Tailwind CSS v4, and Supabase. The project targets mixed-sport athletes (water polo, CrossFit, cycling, gym, running, swimming, etc.).

### Tech Stack

- **Framework**: Next.js 15 with App Router (`src/app/`)
- **Language**: TypeScript (strict mode)
- **Styling**: Tailwind CSS v4 via `@tailwindcss/postcss`
- **Backend**: Supabase (PostgreSQL + Auth + APIs) — not yet connected
- **Package Manager**: pnpm (lockfile: `pnpm-lock.yaml`)

### Common Commands

| Action | Command |
|--------|---------|
| Install deps | `pnpm install` |
| Dev server | `pnpm dev` (port 3000) |
| Lint | `pnpm lint` |
| Build | `pnpm build` |
| Start prod | `pnpm start` |

### Caveats

- Tailwind v4 uses `@import "tailwindcss"` in CSS instead of `@tailwind` directives. Configuration is in `postcss.config.mjs` using `@tailwindcss/postcss`.
- The `next-env.d.ts` file is auto-generated by Next.js — do not edit manually.
- `pnpm.onlyBuiltDependencies` in `package.json` allowlists `sharp` and `unrs-resolver` for native build scripts (avoids interactive `pnpm approve-builds` prompt).
- Supabase environment variables (`NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY`) are not yet configured — the app runs without backend connectivity in demo mode.
